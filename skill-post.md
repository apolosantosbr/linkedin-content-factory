# SKILL: LINKEDIN POST — Manual de Treinamento

> **Missao:** Escrever posts de LinkedIn que geram alcance, engajamento e posicionam Apolo como autoridade.
> **Output:** Post completo pronto para publicar, formatado para mobile, com hook, corpo e CTA.

---

## CONTEXTO OBRIGATORIO

Antes de escrever qualquer post, leia `brand-voice.md` para tom, estilo e regras de linguagem.

---

## 1. ANATOMIA DO POST PERFEITO

```
┌─────────────────────────────────────┐
│ HOOK (max 210 caracteres)           │  ← Decide se a pessoa clica "Ver mais"
│                                     │     60-70% sao perdidos aqui
├─────────────────────────────────────┤
│                                     │
│ CORPO (1.300-1.900 caracteres)      │  ← Entrega valor, conta historia,
│ Paragrafos de 1-2 linhas            │     apresenta dados ou framework
│ Linha em branco entre cada um       │
│ Mobile-first (escaneavel)           │
│                                     │
├─────────────────────────────────────┤
│ CTA (pergunta especifica)           │  ← Gera comentarios e boost algoritmico
├─────────────────────────────────────┤
│ Hashtags (3-5, no final)            │  ← Categorizacao, nao alcance
└─────────────────────────────────────┘
```

## 2. HOOKS — A PARTE MAIS IMPORTANTE

### Tipos de Hook que Funcionam (com exemplos)

**1. Afirmacao Ousada**
- "Vibe coding vai acabar com 80% das agencias de software em 3 anos."
- "O melhor profissional de marketing que eu ja contratei nao e humano."
- "Eu construi uma ferramenta em 2 horas que substituiu um time de 4 pessoas."

**2. Numero Chocante**
- "87% das empresas usam IA. Apenas 12% geram resultado com ela."
- "Gastei R$0 em ads e gerei 340 leads em 30 dias. So com LinkedIn."
- "Uma unica automacao me economiza 23 horas por semana."

**3. Opiniao Contraria**
- "Opiniao impopular: a maioria dos cursos de IA sao inutils."
- "Todo mundo fala em 'escalar'. Eu falo em 'simplificar'."
- "Networking nao e sobre quantidade. E sobre quem te atende o telefone as 23h."

**4. Historia Pessoal**
- "Eu estava prestes a desistir quando recebi aquele email."
- "Meu maior erro em marketing me custou 6 meses de trabalho."
- "Ha 2 anos, eu nao sabia o que era um prompt. Hoje, e minha principal ferramenta."

**5. Provocacao/Pergunta**
- "Voce esta usando IA ou a IA esta usando voce?"
- "Se voce nao sabe explicar o que faz em uma frase, voce nao sabe o que faz."
- "Qual foi a ultima vez que voce aprendeu algo que mudou como voce trabalha?"

**6. Insider/Exclusivo**
- "O que ninguem te conta sobre vibe coding:"
- "Depois de 100+ projetos com IA, aqui esta o que realmente funciona:"
- "3 ferramentas que todo founder deveria usar (e provavelmente nao conhece)."

### Regras do Hook
- **MAXIMO 210 caracteres** (corte do "Ver mais" no LinkedIn)
- **Primeira linha = promessa ou tensao** — a pessoa precisa de uma razao para clicar
- **Nunca comece com "Oi pessoal" ou "Bom dia"** — desperdicam caracteres preciosos
- **Nunca comece com hashtag**
- **Pode comecar com dado, afirmacao ou pergunta** — nunca com contexto

## 3. CORPO — ESTRUTURA POR FRAMEWORK

### Framework AIDA (Educativo)
```
[Hook: Atencao com dado ou afirmacao]

[Interesse: Por que isso importa para voce]

[Desejo: O que muda quando voce aplica]

[Acao: Passo pratico ou CTA]
```

### Framework PAS (Problema-Solucao)
```
[Hook: Identifica a dor]

[Agitacao: Mostra o custo de nao resolver]

[Solucao: Apresenta o caminho com clareza]
```

### Framework BAB (Transformacao)
```
[Hook: Antes — como era]

[Depois — como ficou]

[Ponte — o que fez a diferenca]
```

### Framework STF (Storytelling)
```
[Hook: Situa o leitor na cena]

[Tensao: O obstaculo ou conflito]

[Resolucao: O aprendizado ou resultado]
```

### Framework MRS (Vulnerabilidade)
```
[Hook: O erro que cometi]

[Realizacao: O que eu entendi]

[Mudanca: O que eu faco diferente agora]
```

### Framework DDI (Dados)
```
[Hook: Dado surpreendente]

[Contexto: Por que esse dado importa]

[Insight: O que isso significa na pratica]

[Acao: O que fazer com essa informacao]
```

## 4. CTA — CHAMADAS PARA ACAO QUE FUNCIONAM

### Alta Conversao
- "Qual [tema especifico] voce mais usa? Comenta aqui."
- "Comenta [PALAVRA] e eu te envio o material completo."
- "Salva esse post pra consultar depois."
- "Se isso foi util, repost pra ajudar alguem da sua rede."
- "Concorda ou discorda? Me diz nos comentarios."

### Media Conversao
- "Qual sua experiencia com [tema]?"
- "Ja passou por algo parecido?"
- "Marca alguem que precisa ler isso."

### NUNCA Usar
- "Curta se voce concorda" (engagement bait — penalizado)
- "O que voce acha?" (vago demais)
- "Me diz ai" (sem direcao)
- Multiplas opcoes de CTA no mesmo post

---

## 5. HASHTAGS

### Regras
- **3 a 5 por post** (mais que isso parece spam)
- **Sempre no final**, nunca no corpo
- **Mix de volume:** 1 grande (>1M seguidores) + 2 medias (100K-1M) + 1-2 nicho (<100K)

## 6. CHECKLIST PRE-PUBLICACAO

- [ ] Hook tem no maximo 210 caracteres?
- [ ] Post tem entre 1.300 e 1.900 caracteres?
- [ ] Paragrafos tem no maximo 2 linhas?
- [ ] Tem linha em branco entre cada paragrafo?
- [ ] Segue um dos 6 frameworks?
- [ ] CTA e especifico (nao generico)?
- [ ] 3-5 hashtags no final?
- [ ] ZERO links no corpo? (link vai no primeiro comentario)
- [ ] Tom alinhado com brand-voice.md?
- [ ] Nao tem slop (game-changer, revolucionario, etc)?
- [ ] Nao tem emojis excessivos (max 2-3)?
- [ ] Leria isso no celular entre duas reunioes? (teste de escaneabilidade)
