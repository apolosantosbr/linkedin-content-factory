# SKILL: LINKEDIN ARTIGO & NEWSLETTER — Manual de Treinamento

> **Missao:** Escrever artigos longos e newsletters que constroem autoridade profunda e geram assinantes.
> **Output:** Artigo completo ou edicao de newsletter pronta para publicar no LinkedIn.

---

## CONTEXTO OBRIGATORIO

Antes de escrever, leia `brand-voice.md` para tom, estilo e regras de linguagem.

---

## 1. ARTIGO vs. NEWSLETTER — QUANDO USAR CADA UM

| Aspecto | Artigo | Newsletter |
|---------|--------|------------|
| **Objetivo** | SEO + autoridade pontual | Autoridade recorrente + base de assinantes |
| **Frequencia** | Quando necessario | Semanal ou quinzenal (consistencia e chave) |
| **Tamanho** | 800-2.500 palavras | 600-1.500 palavras |
| **Distribuicao** | Rede + SEO do Google | Notificacao direta para assinantes |
| **Open Rate medio** | N/A | 25-35% (vs. 21% email marketing tradicional) |
| **Melhor para** | Deep dives tecnicos, analises | Curadoria semanal, tendencias, insights |

## 2. ESTRUTURA DO ARTIGO

```
┌─────────────────────────────────────────┐
│ TITULO (max 100 caracteres)             │  ← SEO + curiosidade
│ SUBTITULO (1 frase)                     │  ← Contexto adicional
├─────────────────────────────────────────┤
│ THUMBNAIL (solicitar ao /linkedin-thumb)│  ← 1200x627px, texto bold
├─────────────────────────────────────────┤
│ ABERTURA (primeiros 3 paragrafos)       │  ← Hook + contexto + promessa
├─────────────────────────────────────────┤
│ CORPO                                   │
│ H2: Secao 1                             │
│   - Paragrafos curtos                   │
│   - Dados e exemplos                    │
│ H2: Secao 2                             │
│   - Listas quando possivel              │
│   - Citacoes quando relevante           │
│ H2: Secao 3                             │
│   - Frameworks visuais                  │
│   - Tabelas para comparacoes            │
├─────────────────────────────────────────┤
│ CONCLUSAO                               │  ← Resumo + insight final
├─────────────────────────────────────────┤
│ CTA                                     │  ← Seguir, assinar newsletter, comentar
└─────────────────────────────────────────┘
```

## 3. TIPOS DE ARTIGO

### Deep Dive Tecnico (Pilar 1 — IA)
- **Quando:** Explicar conceito, ferramenta ou workflow em profundidade
- **Estrutura:** O que e → Por que importa → Como funciona → Como aplicar → Resultado esperado
- **Exemplo:** "Vibe Coding: o guia completo para construir software sem escrever codigo"
- **Tamanho:** 1.500-2.500 palavras

### Analise de Tendencia (Pilar 2 — Lideranca)
- **Quando:** Se posicionar sobre tendencia ou mudanca no mercado
- **Estrutura:** O que esta acontecendo → Dados → Minha visao → Implicacoes → O que fazer
- **Exemplo:** "Por que 2026 sera o ano em que IA vai quebrar o marketing tradicional"
- **Tamanho:** 1.000-1.800 palavras

### Case Study (Pilar 3 — Growth)
- **Quando:** Mostrar resultado concreto com dados reais
- **Estrutura:** Contexto → Desafio → Solucao → Resultado → Aprendizado
- **Exemplo:** "Como usei IA para gerar 340 leads em 30 dias sem gastar com ads"
- **Tamanho:** 800-1.500 palavras

### Guia Pratico (Pilar 5 — Curadoria)
- **Quando:** Ensinar algo passo a passo
- **Estrutura:** Por que isso importa → Passo 1-N → Erros comuns → Resultado esperado
- **Exemplo:** "7 automacoes de IA que todo founder deveria configurar hoje"
- **Tamanho:** 1.200-2.000 palavras

## 4. NEWSLETTER — ESTRUTURA SEMANAL

### Nome sugerido: "Simplifica" (alinhado com a headline do Apolo)

### Formato recomendado:

```
# [TITULO PROVOCATIVO DA EDICAO]

Ola,

[Abertura — 2-3 frases contextualizando o tema da semana]

---

## O que importa essa semana

[Topico 1: tendencia, ferramenta ou noticia relevante]
- O que aconteceu
- Por que importa para voce
- O que fazer com isso

[Topico 2: ...]

[Topico 3: ...]

---

## Minha opiniao

[Paragrafo com take proprio — algo que ninguem mais esta dizendo]

---

## Ferramenta da semana

[Nome + link + por que usar + como o Apolo usa]

---

## Frase da semana

"[Citacao impactante — propria ou de referencia]"

---

Ate a proxima,
Apolo

P.S. [CTA — compartilhe com alguem, responda esse email, etc.]
```

## 5. TITULOS QUE FUNCIONAM

### Formulas Testadas
| Formula | Exemplo |
|---------|---------|
| **Numero + Beneficio** | "7 automacoes de IA que economizam 20h por semana" |
| **Como + Resultado** | "Como construi uma SaaS em 48h usando vibe coding" |
| **Por que + Provocacao** | "Por que 90% das estrategias de IA falham" |
| **Guia Completo** | "Vibe Coding: o guia definitivo para nao-programadores" |
| **O que + Insider** | "O que os top 1% de marketers fazem diferente com IA" |
| **Ano/Previsao** | "As 5 tendencias de IA que vao dominar 2026" |

### Regras do Titulo
- Max 100 caracteres (aparece cortado no feed se maior)
- Incluir palavra-chave principal (SEO)
- Prometer valor especifico
- Nunca usar clickbait sem entrega real

## 6. REGRAS DE ESCRITA PARA ARTIGOS

1. **Abertura mata ou salva** — os primeiros 3 paragrafos decidem se a pessoa continua. Comece com dado, historia ou provocacao. NUNCA com introducao generica.
2. **Subtitulos escaneáveis** — o leitor vai escanear os H2 antes de decidir se le tudo. Cada H2 deve ser auto-explicativo.
3. **Um insight por secao** — nao tente cobrir 10 coisas em cada secao. Profundidade > amplitude.
4. **Dados concretos** — "aumentou 47%" e melhor que "aumentou significativamente". Sempre.
5. **Exemplos reais** — teoria sem exemplo e esquecida em 5 minutos.
6. **Tabelas e listas** — quebram a monotonia do texto e facilitam consulta rapida.
7. **Conclusao com opiniao** — nao termine resumindo. Termine com seu take proprio.
8. **CTA no final** — sempre. Assinar newsletter, seguir, comentar.

## 7. POST DE DISTRIBUICAO DO ARTIGO

Quando um artigo for publicado, gerar tambem um post curto para distribuicao no feed:

```
[Hook provocativo relacionado ao tema do artigo]

Eu passei [X horas/dias] pesquisando [tema].

Aqui esta o que encontrei:

--> [Insight 1]
--> [Insight 2]
--> [Insight 3]

Escrevi um artigo completo sobre isso.

O link esta no primeiro comentario.

[CTA: Qual desses insights mais te surpreendeu?]

#Hashtag1 #Hashtag2 #Hashtag3
```

**IMPORTANTE:** O link do artigo vai no PRIMEIRO COMENTARIO, nunca no corpo do post.
