# SKILL: LINKEDIN REVISAR — Manual de Treinamento

> **Missao:** Revisar qualquer conteudo LinkedIn para garantir qualidade maxima em tom, algoritmo, hooks, CTAs e alcance.
> **Output:** Conteudo revisado com changelog de todas as alteracoes e justificativas.

---

## CONTEXTO OBRIGATORIO

Antes de revisar qualquer conteudo, leia `brand-voice.md` como referencia absoluta.

---

## 1. CHECKLIST DE REVISAO — 7 DIMENSOES

Cada conteudo deve ser avaliado nestas 7 dimensoes com nota 1-5:

| # | Dimensao | Peso | O que avaliar |
|---|----------|------|---------------|
| 1 | **Hook** | 25% | Prende em 210 chars? Gera curiosidade? |
| 2 | **Valor** | 20% | Entrega algo util, novo ou surpreendente? |
| 3 | **Tom** | 15% | Alinhado com brand-voice.md? |
| 4 | **Estrutura** | 15% | Mobile-first? Escaneavel? Paragrafos curtos? |
| 5 | **CTA** | 10% | Especifico? Gera acao? |
| 6 | **Algoritmo** | 10% | Sem links? Hashtags corretas? Tamanho ideal? |
| 7 | **Slop** | 5% | Zero cliches, jargao vazio, linguagem de IA? |

**Score minimo para aprovar: 4.0/5.0**
**Abaixo de 4.0: devolver com correcoes obrigatorias**

---

## 2. REVISAO DO HOOK

### Criterios
- [ ] Max 210 caracteres? (HARD LIMIT — contar caracteres)
- [ ] Cria tensao, curiosidade ou surpresa?
- [ ] Nao comeca com "Oi", "Bom dia", "Pessoal"?
- [ ] Nao comeca com hashtag?
- [ ] Usa um dos tipos comprovados? (afirmacao ousada, numero, opiniao contraria, historia, pergunta, insider)
- [ ] Faria VOCE clicar em "Ver mais"?

### Red Flags (reescrever obrigatoriamente)
- Hook generico: "Vou compartilhar algo interessante"
- Hook vago: "Muita coisa esta mudando no mercado"
- Hook que entrega tudo: "Aqui estao 5 dicas de IA" (sem tensao)
- Hook longo demais (>210 chars)

---

## 3. REVISAO DO CORPO

### Criterios de Estrutura
- [ ] Paragrafos de max 2 linhas?
- [ ] Linha em branco entre cada paragrafo?
- [ ] Comprimento entre 1.300-1.900 caracteres (posts)?
- [ ] Segue um framework claro (AIDA, PAS, BAB, STF, MRS, DDI)?
- [ ] Mobile-first (testado mentalmente em tela pequena)?

### Criterios de Conteudo
- [ ] Uma ideia central clara?
- [ ] Dados concretos (numeros, nao "muito" ou "bastante")?
- [ ] Exemplos reais ou experiencias proprias?
- [ ] Progressao logica (cada paragrafo leva ao proximo)?
- [ ] Sem repeticao desnecessaria?

---

## 4. REVISAO DO TOM

### Alinhamento com Brand Voice
- [ ] 70/20/10 respeitado? (educativo/provocativo/pessoal)
- [ ] Direto e sem enrolacao?
- [ ] Confiante sem ser arrogante?
- [ ] Simplificador (founders leem rapido)?
- [ ] Primeira pessoa quando apropriado?

### Detector de Slop (TOLERANCIA ZERO)
Palavras e expressoes PROIBIDAS — se encontrar, substituir imediatamente:

| PROIBIDO | SUBSTITUIR POR |
|----------|---------------|
| "revolucionario" | descrever o que realmente mudou |
| "game-changer" | mostrar o impacto com dados |
| "disruptivo" | explicar o que muda na pratica |
| "sinergia" | explicar a combinacao especifica |
| "alavancagem" | "crescimento" ou "escala" |
| "incrivel" | ser especifico sobre o que impressiona |
| "transformador" | descrever a transformacao |
| "basicamente" | deletar (sempre desnecessario) |
| "na verdade" | deletar ou reformular |
| "simplesmente" | deletar |
| "inovador" | descrever a inovacao |
| "paradigma" | ser especifico |
| "ecossistema" | "mercado" ou "rede" ou ser especifico |
| "de ponta" | descrever o diferencial |
| "cutting-edge" | idem |

### Detector de IA (CRITICO)
O LinkedIn penaliza conteudo detectado como 100% IA. Verificar:
- [ ] Tem voz humana? (opiniao, emocao, experiencia pessoal)
- [ ] Tem imperfeicoes naturais? (nao e perfeito demais)
- [ ] Inclui referencia pessoal ou experiencia propria?
- [ ] Nao segue padrao generico de "lista de 5 itens com introducao e conclusao"?

---

## 5. REVISAO DO CTA

### Criterios
- [ ] CTA presente? (NUNCA publicar sem CTA)
- [ ] Especifico (nao generico)?
- [ ] Pergunta direta (nao "o que voce acha?")?
- [ ] Uma unica acao (nao multiplas opcoes)?
- [ ] Alinhado com o objetivo do post (engajamento vs. save vs. share)?

### CTAs por Qualidade
| Nivel | Exemplo | Veredicto |
|-------|---------|-----------|
| EXCELENTE | "Qual a unica metrica que voce mais acompanha no seu negocio?" | Aprovar |
| BOM | "Ja usou vibe coding? Me conta como foi." | Aprovar |
| MEDIO | "Concorda? Comenta ai." | Melhorar |
| FRACO | "O que voce acha?" | Reescrever |
| PROIBIDO | "Curta se voce concorda" | Rejeitar (engagement bait) |

---

## 6. REVISAO ALGORITMICA

### Checklist do Algoritmo 2026
- [ ] ZERO links no corpo do post?
- [ ] Links somente no primeiro comentario?
- [ ] 3-5 hashtags no final (nao no corpo)?
- [ ] Mix de hashtags: 1 grande + 2 medias + 1-2 nicho?
- [ ] Tamanho ideal? (1.300-1.900 chars para post, 800-2.500 palavras para artigo)
- [ ] Nao e engagement bait explicito?
- [ ] Conteudo nativo (sem embed de link externo)?
- [ ] Consistente com os 5 pilares de conteudo?

---

## 7. REVISAO DE CARROSSEL (ADICIONAL)

Se o conteudo for carrossel, verificar tambem:
- [ ] Exatamente 7 slides?
- [ ] 1080x1350px?
- [ ] 1 ideia por slide?
- [ ] Slide 1 com titulo provocativo (max 8 palavras)?
- [ ] Teaser no rodape de cada slide?
- [ ] Slide 7 com CTA + @apolosantos?
- [ ] Fonte min 28px no corpo?
- [ ] Cores dentro da paleta?

---

## 8. REVISAO DE ARTIGO (ADICIONAL)

Se o conteudo for artigo, verificar tambem:
- [ ] Titulo max 100 chars com keyword?
- [ ] Abertura prende em 3 paragrafos?
- [ ] Subtitulos escaneáveis?
- [ ] Dados concretos em cada secao?
- [ ] Conclusao com opiniao (nao resumo)?
- [ ] Post de distribuicao criado?
- [ ] Thumbnail solicitada?
